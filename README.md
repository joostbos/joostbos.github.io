# Joost Bosschert – VR Portfolio

This repository contains the public portfolio website for Joost Bosschert.

**Website:** https://joostbos.github.io

## Contents

- `index.md` – homepage
- `projects.md` – selected project overview
- `projects/` – individual project pages
- `about.md` – introduction
- `contact.md` – contact details
- `assets/main.scss` – visual styling
- `assets/images/` – project screenshots and cover images
- `assets/videos/` – notes for adding gameplay videos

The site is built with GitHub Pages, Jekyll, Markdown and the Minima theme. The layout and styling have been prepared in the repository; no HTML editing is needed for routine text and project updates.
